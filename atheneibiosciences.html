Approach

A research preview of the core idea

Below is a simplified sketch of how ProlifOT frames a proliferating population — not a public API, just the shape of the problem.

python (research preview) 
# unbalanced transport between a proliferating
# source population and a target distribution
from prolifot import UnbalancedBridge

bridge = UnbalancedBridge(
    growth_rate=r,          # allows mass creation
    entropy_reg=epsilon,    # Schrödinger bridge regularization
)

plan = bridge.solve(
    source=population_t0,
    target=target_distribution,
)

# plan.mass_created tells you how much of the
# target is genuinely new growth, not transported mass

Illustrative pseudocode — ProlifOT is a research framework, not a released package.

Unbalanced, not balanced

Mass is created

Classical OT conserves mass. Ours doesn't have to — because proliferating cells don't.

Multi-scale

One geometry, every scale

A single cell's trajectory and a bioreactor's population dynamics are the same object, viewed at different resolutions.

Regime-aware

Knows when it's unstable

Built on the dynamical-systems view that scaling can push a population from stable to periodic to chaotic — and accounts for which regime it's in.
